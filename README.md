# Frontend Projects

This repository contains a collection of small front-end projects focused on UI design, layout, and interactive web elements.

## Included Projects

### 1. GoDaddy.com
A static landing page inspired by the GoDaddy website, built using HTML and CSS. It includes hero sections, product highlights, and media-rich layout styling.

### 2. Gradient Generator
A simple interactive gradient generator built with HTML, CSS, and JavaScript. It allows users to generate color combinations and preview the CSS gradient code.

## Tech Stack

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone the repository.
2. Open any project folder.
3. Open the `index.html` file in a browser.

For a better local preview, you can also serve the folder with a simple local web server, for example:

```bash
cd "Gradient Generator"
python -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.

## Purpose

These projects are intended for learning, practice, and experimentation with modern front-end design and development techniques.
